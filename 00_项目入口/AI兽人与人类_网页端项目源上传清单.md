# AI兽人与人类｜网页端项目源上传清单

> 用途：当 ChatGPT 网页端无法稳定通过 GitHub 读取仓库，或需要手动更新 Project Source / Knowledge 时，按本清单上传当前正本 Markdown。
> 原则：只上传“当前正本”和必要入口，不上传旧版本、归档、早期讨论清单和未整理片段，避免网页端混用旧设定。
> 当前规则：网页端应优先读取入口文件；新讨论先进入网页端同步输入箱；正本吸收由本地 Codex 统一整理。

---

## 1. 上传总原则

不要把仓库里的所有 `.md` 一次性全量上传。

建议上传：

- 当前项目入口；
- 当前总纲；
- 当前正本设定；
- 当前人物与场景设定；
- 必要的网页端同步输入箱。

默认不要上传：

- 旧版本；
- 归档；
- 早期素材；
- 未吸收讨论清单；
- 待整理片段；
- 旧版阅读索引。

原因：

- 网页端检索可能命中旧版设定；
- 早期讨论中有已废弃术语和旧称呼；
- 归档文件可能与当前正本冲突；
- 所有文件一起上传会增加“看得到但找错”的风险。

## 11. 一句话提醒

全量上传“当前正本”可以；全量上传“仓库里所有 Markdown”不建议。

网页端需要的是干净、当前、少冲突的项目源，而不是所有历史材料。
