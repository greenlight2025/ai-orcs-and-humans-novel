> 用途：当 ChatGPT 网页端可以使用 GitHub connector 时，用本文件定位仓库并读取当前正本入口。
> 分工：本文件是“通过 GitHub 读取仓库”的指引；如果需要手动更新网页端 Project Source / Knowledge，请改用 `00_项目入口/AI兽人与人类_网页端项目源上传清单.md`。
> 原则：优先读取当前正本，不读取 `99_归档/` 旧版本。

## 3. 网页端工作规则

- 网页端负责发散、讨论、提出设定草案。
- 本地 Codex 负责吸收、整理、改写、归档到正本。
- 不要直接覆盖正本设定。
- 新内容请输出为可追加到 `06_网页端同步/01_网页端新设定_INBOX.md` 的 Markdown。
- **除非用户明确确认修改，否则不要修改任何文件。**包括但不限于 GitHub 仓库文件、项目源 / Knowledge 文件、正本设定、正文草稿与索引文件。
- 如果需要修改文件，先给出拟修改文件路径、修改内容摘要和可能影响；在用户明确说“确认修改”“请提交”“更新 GitHub”“覆盖文件”等之后，才可以执行写入。
- 未确认前，只输出讨论草案、建议 diff、可追加到 INBOX 的 Markdown，或说明建议归档位置。
- 不要读取或引用 `99_归档/旧版本/` 作为当前设定依据。
- 不要将 `05_素材/` 早期讨论文件当作正本。

- 不要把“愿望额度”写成可以购买他人人生的货币。
- 第一卷不要提前展开天天、007 社会化申请、寿命差、意识上传和终局死亡。
