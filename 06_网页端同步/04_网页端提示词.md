# 网页端提示词

> 用途：在 ChatGPT 网页端连接 GitHub 仓库后，复制以下提示词，让网页端按本地项目规则讨论新设定。

## 1. 开始讨论前的提示词

```text
请读取这个 GitHub 仓库中的以下文件，作为本轮讨论的项目规则：

- 00_项目入口/项目总览.md
- 00_项目入口/术语与文风手册.md
- 00_项目入口/AI兽人与人类_项目源MD阅读索引_v3.md
- 02_大纲/AI兽人与人类_第一人称AI视角长篇大纲_v4_慢节奏社会生活版.md

请基于这些文件讨论新设定。

注意：
- 不要把复育人类写成奖品、资源、样本、商品或愿望响应物。
- 不要让 A7-001 像全知作者一样读心。
- 不要把“每日基础生活额度”写成生存资格。
- 第一卷不要提前展开天天、007 社会化申请、寿命差、意识上传和终局死亡。
- 新设定请输出为可追加到 `06_网页端同步/01_网页端新设定_INBOX.md` 的 Markdown 格式。
- 不要直接覆盖正本设定。
```

## 2. 生成新设定时的提示词

```text
请围绕以下主题生成设定草案，并严格遵守仓库中的术语与文风手册：

主题：

要求：
- 先给出内容摘要；
- 再给出可直接追加到 `06_网页端同步/01_网页端新设定_INBOX.md` 的 Markdown；
- 标注可能归档位置；
- 标注与现有设定可能冲突的点；
- 不要直接改写正本文件。
```

## 3. 网页端输出格式

```md
## YYYY-MM-DD｜主题名称

来源：网页端 / GitHub 讨论

### 内容摘要


### 原始片段


### 可能归档位置


### 待确认问题


```

## 4. 回到本地后的提示词

```text
请读取 `06_网页端同步/01_网页端新设定_INBOX.md`，检查其中尚未吸收的网页端新设定。

请按以下规则处理：
- 与 `术语与文风手册.md` 对齐；
- 与 `项目源MD阅读索引_v3.md` 和总纲 v4 对齐；
- 判断应吸收到哪个正本文件；
- 必要时改写为正本口吻；
- 更新 `03_已吸收记录.md`。
```
